# 从旧待办到阶段复盘

这里的月历和待办属于阶段行动。首页的 Super Productivity 操作见[日常工作与 AI 工作流](workbench-plugins.md)。

1. 从「更多工具 → 旧待办」打开月历。选择日期，按 Enter 添加全天待办，也可点击时间轴上的时刻后录入。截止日期可在添加时指定。
2. 拖动任务手柄到日历日期或半小时时间格。原截止日期保留，倒计时会自动更新。也可以点手柄打开日期和时间表单，或点击圆圈完成任务。
3. 查看当天的活动记录。原「今日／待安排」列表可从窗口顶部的「待办列表」进入。
4. 进入「主线与分支」，把目标拆成可验收的交付物和行动。P0 作为主线，P1/P2 作为分支；列表显示行动完成数和下一交付。每周可选最多三项交付、每天可选最多三项重点，这不会限制待办看板。
5. 需要协助时点击「交给 AI」。在运行页检查材料后确认发送。若出现「待决策」，选一个答案，再预览并继续。没有配置模型时可运行规则工作纸。
6. 从「待我确认」打开产物，检查后接受。回到原待办按实际结果更新状态；运行验收不会自动完成原事项。失败时可重新规划。
7. 每周在「主线与分支 → 本周重点与复盘」记录实际结果、卡点和下周重点。周期结束后再开下一阶段，旧阶段可从历史回看。

把私人目标设为「只在详情显示」可让它及关联任务退出旧待办和旧任务总览。想法在「更多工具 → 想法库」单独整理；文章从创作草稿推进，知识从学科和主题进入。
