# 创作发布指南

## 独立文章

1. 在「创作」查看文章及状态，展开「新建文章草稿」填写正文或提纲。
2. 持续在文章详情编辑 Markdown；文章不要求选择随想或知识卡。
3. 需要发布或视频时，从文章详情进入对应工作台。
4. 普通随想、周回顾和知识卡不显示公众号或视频入口。

作者可以自行参考知识库，但工作台不建立强制文章素材图谱。

## 微信公众号

1. 进入 `/publish`，选择未归档文章。
2. 忠实转换不调用模型；预览会去除重复首个标题、危险链接和私人 Vault 路径。
3. 可调整受控主题色、字号、字体、首行缩进和对齐，参数不会回写 Markdown。
4. 在手机宽度和编辑器宽度间切换，检查格式诊断。
5. 人工发布可点击“一键复制公众号正文”，再到公众号后台填写标题和摘要。
6. 草稿箱直推先到 `/settings/wechat` 把 AppID 和 AppSecret 写入 macOS 钥匙串，并显式测试凭证与 IP 白名单。
7. 在发布页填写标题、作者和摘要，选择已有私有封面或现场上传 PNG/JPEG。
8. 点击“检查并准备推送”；本地预检会固化公式和图片，未保存的润色候选不能直接推送。
9. 在确认页核对账号、封面、正文体积、图片和公式数量，再明确创建公众号草稿。
10. 成功或结果未知时都进入公众号后台人工检查；系统不会自动发表或盲目重试。

幻想栈风格润色需要显式模型任务。保存候选会创建新的文章版本并关联原文章，不覆盖原文。

## 视频项目

1. 从文章创建视频项目，设置平台、画面比例、时长、表达类型、受众和风格。
2. 系统按文章段落生成确定性初始分镜。
3. 编辑镜头时长、旁白、画面、字幕和素材引用。
4. 导出 Storyboard YAML、旁白稿、SRT、Remotion Props、OpenCut brief 和素材副本。
5. 使用 Remotion 制作程序化画面，或把交接材料送入 OpenCut 人工精修。

当前不自动渲染视频、转录音频或修改 OpenCut 时间线。

## 创作边界

- 微信公众号是文章导出方式，不是独立内容类型。
- 视频项目是文章派生制作物，不进入正式知识图谱。
- 周回顾保持中性，不套用公众号文风。
- 排版、分镜和候选稿都不能覆盖原始文章。
- 微信凭证不进入 Markdown、SQLite、日志、备份或仓库。

功能限制见 [公众号与视频](../features/publishing-video.md)。
