# 从待办到 AI 产物

1. 打开「日常工作」。顶部可在中文与 English 之间切换，Inbox 是收集未归入项目的待办入口。月历适合排日期，周视图适合拖到具体时段。点「新建任务」或用 Super Productivity 的键盘快捷键录入。用任务上的播放按钮开始计时。
2. 从任务右键菜单选择「插件操作 → 交给 AI」。输入任务目标，点击「预览外发」，检查材料和模型后再确认。如果还没设置模型，从「模型与成本」打开配置说明。
3. 到「AI 工作流」查看 Worker 和队列状态。点事项打开时间线，再切换同一事项的其他轮次。工作台需要你做决定时，从卡片打开工作项，选择预设选项或填写文字，检查续跑预览后再确认。如果模型响应超时，重新检查预览并确认重试。
4. 阅读候选稿，点「验收此产物」。任务本身办完后回到「日常工作」勾选完成。旧待办和旧执行记录在「插件」菜单中。

从 AI 工作流可以暂停、恢复或立即触发规则。立即运行会先生成待确认项。规则修改由本机维护命令校验。

普通 Autoloop Ask 可在收件箱直接回答；切到「近期已处理」查看续跑链接。普通 Notice 填写处理原因后可以结案。查找旧轮次时先筛选，再用「加载更早的轮次」扩大范围。页面提示数据过期时，原记录仍可查看；服务恢复后会自动补齐，亦可手动刷新。

AI 工作流页顶部显示执行后端。显示 DeepSeek Harness 时，预览确认后由本机 Harness 处理，结果和用量出现在该轮时间线。立即运行规则和计划触发都先生成待确认工作项，确认后才调用模型。
