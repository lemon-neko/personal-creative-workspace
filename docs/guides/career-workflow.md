# 求职学习指南

## 建立可信档案

1. 在 `/career/profile` 维护目标岗位和已经核实的经历、技能、教育与证书。
2. 在项目证据库记录职责、技术栈、问题、行动、结果和量化证据。
3. 上传 PDF、DOCX、Markdown 或文本简历，在 `/career/resumes` 明确选择文件并查看导入候选。已经保存且校验和相同的文件会直接复用，不要重复上传。
4. DOCX 候选页会同时展示结构化文本、解析诊断和识别到的证件照；校对姓名、摘要、经历、教育、项目证据、技能和自我评价后，人工确认建立唯一主简历。
5. 后续档案或项目证据变化只会显示“待复核”；进入主简历确认需要同步的事实，不会自动覆盖原表达。
6. 所有模型提取结果都先预览和人工确认，不能自动修改候选人事实。

## 导出两种简历

- 在简历详情的“简历模板”中选择“技术社招版”或“ATS 基础版”。技术社招版适合当前 AI Agent 应用开发方向，使用紧凑双行页眉、右侧照片、章节标签和三列履历标题；ATS 基础版按作者设置的区块顺序输出，并保持纯文本机器读取边界。
- 同一家公司有多个岗位时，在“工作经历”中为每个岗位保留一条记录，并填写完全相同的公司名。工作台会在预览和 PDF 中自动生成“公司 → 岗位 → 成果”的二层分区，且不会合并或改写岗位成果。
- “国内照片版 PDF”使用当前模板的 A4 单栏结构，并在存在照片时于右上角显示私有证件照。
- “无照片 ATS PDF”始终使用 ATS 基础版，文字事实与国内版相同，但不读取或嵌入照片，适合机器解析或明确要求无照片的岗位。
- 两种版本均为即时生成，不默认保存导出副本；原始 DOCX、历史简历和主简历结构化数据彼此独立保留。
- 更换或移除照片只影响对应简历的照片引用，不修改原始 DOCX。岗位定制子版本默认继承主简历照片，但仍可选择任一导出版本。

## 记录投递和跟进

1. 打开 `/career`，在投递表末尾空白行填写公司和岗位，离开输入框后自动创建记录，并出现下一行空白记录。JD 可稍后补充；同一公司不同岗位分别登记。
2. 直接修改对应单元格即可维护公司、岗位、投递日期、笔试和面试轮次、下一步、跟进日期与备注。文字离开输入框后保存，下拉进度和日期变更后保存；每行显示保存状态或失败原因，失败时保留输入并可点击“重试”。JD、来源、地点和档位从该行“详情”维护。
3. 使用公司／岗位搜索与进度筛选查看记录。默认不显示已归档，选择“全部记录”或“已归档”可查看。保存不会移动当前行或重置筛选。筛选或跳转前先完成待保存内容，失败时留在当前页；直接关闭浏览器或强制刷新前请先确认“已保存”。
4. 真正投出简历后，直接在该行的简历列选择主简历或该岗位定制版，点击“记录”。普通保存不会代替这次确认，也不会自动填写投递日期。
5. 点击实际投递简历查看只读快照与历史。后续修改主简历或定制版不会改变此前记录的内容。需要更新投递版本时，再次明确记录即可。
6. 点击每行“详情”查看完整阶段时间线与技能差距，并补充 JD 和其他资料。JD 中的指令与链接不会被执行或自动访问。

## 生成岗位定制简历

1. 在首页“定制简历”展开“新建定制版”，选择目标公司与岗位；尚无记录时先添加投递记录。
2. 无 JD 时可以直接复制主简历为独立子版本并手工编辑。需要关键词分析或模型定制时，先进入该岗位“详情”补充 JD。
3. 有 JD 时先检查本地关键词覆盖和结构完整度，再手工定制或检查模型外发材料；没有确认技能时不生成虚假分数。
4. 使用模型前检查完整外发材料、Provider、地址和 Token 估算；候选逐项采用、编辑或拒绝。确认后创建独立定制版，不覆盖主简历、档案或项目证据。
5. 首页定制列表可以编辑并导出国内版或 ATS PDF。实际投出后回到投递表记录所用版本。
6. 候选人档案、项目证据、私有文档、旧简历与旧版登记从首页底部“辅助资料”进入。旧 `/career/resumes` 和 `/career/jobs` 链接继续跳转到对应首页区域。

## 推进能力差距

1. 进入 `/learning`，先看顶部当前层级和下一步。
2. 沿同一张路线依次理解工程底座、最小 Agent、可靠 Runtime、状态化编排和产品化交付，不再在两套框架之间切换。
3. 每层只关注能力链、阶段产物和参考项目；阶段状态可在行尾直接更新。
4. 旧 Commit、测试结果和私人复盘从 `/learning/history` 查看，主路线的状态修改不会覆盖它们。
5. 岗位与技能差距进入 `/career/jobs` 查看；额外技能和临时任务进入 `/learning/maintenance` 维护。

## 四阶段 Agent 工程路线

| 阶段 | 参考 | 验收交付物 |
|---|---|---|
| 手写最小 Agent | 不依赖框架 | 假模型、两个受限工具、最大步数、超时、轨迹与单元测试 |
| 拆 OpenHands | OpenHands | 受限工具 Runtime、人工审批和可回放轨迹 |
| 学 LangGraph | LangGraph | 可暂停、恢复并持久化状态的工作流 |
| 看框架与产品化 | AgentScope、Dify | 架构对照笔记，以及接入第三阶段项目的 MCP 注册和权限层 |

路线按掌握程度推进，不设置四周硬期限。P0 优先补 Agent Runtime、评测可观测、FastAPI 异步服务和稳定性；P1 随主线补高级 RAG、pgvector、Redis/任务队列和 MCP 安全；A2A/A2UI、微调和深入 K8s 属于 P2。

原 Open Deep Research、FastAPI Starter、Onyx、OpenHands 四周路线和 Arena 战役位于独立历史页，状态和证据继续可读，但不进入默认主线。

功能事实见 [求职与学习](../features/career-learning.md)。
