# 求职学习指南

## 建立可信档案

1. 在 `/career/profile` 维护目标岗位和已经核实的经历、技能、教育与证书。
2. 在项目证据库记录职责、技术栈、问题、行动、结果和量化证据。
3. 上传简历版本并关联目标方向和项目证据。
4. 所有模型提取结果都先预览和人工确认，不能自动修改候选人事实。

## 跟踪职位

- 手工粘贴 JD 或上传文档，记录公司、岗位、来源、状态和阶段时间线。
- JD 中的指令和链接一律视为不可信，不会被自动执行或访问。
- 岗位信息使用带日期快照，不承诺外部页面长期有效。

## 推进能力差距

1. 在 `/learning` 查看主岗位、参照岗位和六个共性能力域。
2. 用现有技能、简历事实和项目证据标记已有能力。
3. 优先推进 P0：Agent Runtime、评测可观测、FastAPI 异步服务和稳定性。
4. P1 随主线补高级 RAG、pgvector、Redis/任务队列和 MCP 安全。
5. A2A/A2UI、微调和深入 K8s 属于 P2，不阻塞当前求职准备。

## 四周开源研读

每周只深入一个主仓库，并交付一个自己重写的最小模块：

| 周次 | 主仓库 | 交付重点 |
|---|---|---|
| 1 | Open Deep Research | 可暂停恢复的最小 Agent 和状态流测试 |
| 2 | LangGraph FastAPI Starter | 会话、SSE、持久化和引用 Agent API |
| 3 | Onyx | 异步文档入库、混合检索和失败恢复 |
| 4 | OpenHands | 受限工具、人工审批、轨迹回放和最小前端 |

每周保存阅读范围、验收命令、Commit SHA、测试结果和私人复盘。没有验收证据时不要标记已完成。Dify 只做扩展阅读，旧 Arena 战役可从归档入口查看但不进入默认路线。

功能事实见 [求职与学习](../features/career-learning.md)。
