# 常见故障

## 页面提示拒绝跨站请求

- 桌面使用 `http://127.0.0.1:8765`，不要混用 `localhost`、局域网 IP 或其他端口。
- 刷新原始表单页后重新提交，避免使用旧 CSRF 页面。
- 手机使用配置的 Tailnet HTTPS 主机，不直接访问 `127.0.0.1:8766`。

## 端口被占用

先确认占用者确实是旧羽白工作台进程，再正常停止并重启。不要盲目结束其他 Python 服务。`/settings/runtime` 可查看当前运行状态。

## Serve 主机不一致

- 使用 `tailscale serve status` 检查实际 HTTPS 主机和目标端口。
- 回到手机设置保存同一个 Tailnet 主机。
- 确认代理目标是 `http://127.0.0.1:8766`，且 Funnel 关闭。

## 手机配对后仍被拒绝

- 确认 Mac 和手机属于同一私人 Tailnet。
- 重新生成未过期配对码。
- 使用系统 Chrome 或已安装 PWA，不要从内置浏览器提交。
- 检查设备是否已在桌面设置中被撤销。

## Tailscale 正常但手机页面打不开

1. 在 `/settings/runtime` 确认手机网关已安装、正在运行且 8766 端口可用。
2. 使用 `.venv/bin/python -m app.runtime status` 检查常驻服务；需要修复时重新执行 `.venv/bin/python -m app.runtime install --mobile`。
3. 使用 `tailscale serve status` 确认私网 HTTPS 入口仍代理到 `http://127.0.0.1:8766`，并确认 Funnel 关闭。
4. 不要直接在手机访问 `127.0.0.1:8766`；手机必须打开设置页展示的 Tailnet HTTPS 地址。

常驻服务必须使用仓库的 `.venv/bin/python`。启动器会保留虚拟环境入口，并向后台进程提供 Tailscale macOS CLI 所需的最小用户运行环境；LaunchAgent 仍不保存模型密钥或正文。

## Obsidian 格式诊断

- 普通笔记进入 `sources/inbox/`，知识模板进入 `knowledge/inbox/`。
- 正式文件必须保留稳定 ID、类型和状态。
- 不直接移动或重命名正式文件；使用迁移预演和确认流程。
- 修复正文后重新扫描外部修改，不删除文件绕过诊断。

## 知识图为空或缺少关系

- 检查卡片是否未归档，并关联有效主题和随想来源。
- 在 Obsidian 设置页扫描修改并重建分层导航。
- 概念不会显示为节点；来源需要点击卡片后展开。

## 发布页或复制异常

- 确认来源类型为 `article`，随想和周回顾不能进入发布页。
- 刷新页面后重新生成预览，查看格式诊断中的图片和公式回退。
- 浏览器剪贴板不可用时会降级为选区复制；粘贴后仍需人工检查图片托管。

## 公众号草稿箱推送失败

- 在 `/settings/wechat` 重新测试凭证和公众号 IP 白名单；测试按钮是显式联网操作。
- `48001 api unauthorized` 表示当前公众号没有对应接口权限。若出现在草稿权限检查或创建草稿阶段，请检查公众号主体、认证状态和草稿接口权限；官方端点与参数测试已通过时，这通常不是代码故障。
- `40164` 表示当前公网 IP 未加入公众号白名单；`40013`、`40125` 分别优先检查 AppID、AppSecret。
- “未内嵌外部图片”表示浏览器未能读取图片。把图片保存到私有 `assets/` 并在 Markdown 中使用本地图片后重试。
- 正文图片需为 PNG、JPEG 或 GIF 且单张小于 1 MB；封面需为 PNG/JPEG 且小于 10 MB。
- “文章版本不一致”表示 Obsidian 或工作台在预检后修改了文章，刷新发布页重新准备即可。
- “结果未知”表示创建草稿请求超时。先登录公众号后台检查，不要立即创建副本。
- AppSecret 不会显示在网页中；需要更换时直接在设置页重新写入钥匙串。

## 搜索缺少最新内容

- 查看 `/settings/search` 的最后同步时间与错误。
- 只有显式“全量重建”才会清空重建索引；普通搜索不会修改内容。
- 重建失败不会影响 Markdown 权威文件。
