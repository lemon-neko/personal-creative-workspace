# 常见故障

## 页面提示拒绝跨站请求

- 桌面使用 `http://127.0.0.1:8765`，不要混用 `localhost`、局域网 IP 或其他端口。
- 刷新原始表单页后重新提交，避免使用旧 CSRF 页面。
- 手机使用配置的 Tailnet HTTPS 主机，不直接访问 `127.0.0.1:8766`。

## 端口被占用

先确认占用者确实是旧羽白工作台进程，再正常停止并重启。不要盲目结束其他 Python 服务。`/settings/runtime` 可查看当前运行状态。

## Serve 主机不一致

- 使用 `tailscale serve status` 检查实际 HTTPS 主机和目标端口。
- 回到手机设置保存同一个 Tailnet 主机。
- 确认代理目标是 `http://127.0.0.1:8766`，且 Funnel 关闭。

## 手机配对后仍被拒绝

- 确认 Mac 和手机属于同一私人 Tailnet。
- 重新生成未过期配对码。
- 使用系统 Chrome 或已安装 PWA，不要从内置浏览器提交。
- 检查设备是否已在桌面设置中被撤销。

## Obsidian 格式诊断

- 普通笔记进入 `sources/inbox/`，知识模板进入 `knowledge/inbox/`。
- 正式文件必须保留稳定 ID、类型和状态。
- 不直接移动或重命名正式文件；使用迁移预演和确认流程。
- 修复正文后重新扫描外部修改，不删除文件绕过诊断。

## 知识图为空或缺少关系

- 检查卡片是否未归档，并关联有效主题和随想来源。
- 在 Obsidian 设置页扫描修改并重建分层导航。
- 概念不会显示为节点；来源需要点击卡片后展开。

## 发布页或复制异常

- 确认来源类型为 `article`，随想和周回顾不能进入发布页。
- 刷新页面后重新生成预览，查看格式诊断中的图片和公式回退。
- 浏览器剪贴板不可用时会降级为选区复制；粘贴后仍需人工检查图片托管。

## 搜索缺少最新内容

- 查看 `/settings/search` 的最后同步时间与错误。
- 只有显式“全量重建”才会清空重建索引；普通搜索不会修改内容。
- 重建失败不会影响 Markdown 权威文件。
