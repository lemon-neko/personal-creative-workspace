# 当前系统基线

## 背景与目标

从本日期开始建立正式更新档案，不逐条回填早期提交。本记录冻结文档重构时的能力边界，供后续功能批次比较。

## 最终行为

- 桌面工作台只在本机回环端口提供，管理随想、正式知识、创作、求职、学习、模型和备份。
- Obsidian 与工作台直接编辑同一份私有 Markdown Vault。
- Android PWA 经 Tailnet 最小网关记录和编辑未归档随想，并读取安全知识快照。
- ModelGateway 统一管理规则、本地、人工和外部模型，任何调用先预览再确认。
- 私人正文、SQLite、附件和备份位于仓库之外。

## 接口与数据

桌面入口为 `127.0.0.1:8765`，移动入口为 `127.0.0.1:8766` 并通过 Tailscale Serve 代理。Markdown 保存内容正文，`workspace.db` 保存结构化关系和可重建索引，`mobile.db` 保存设备会话和幂等回执。

## 兼容与回滚

本记录不修改程序或数据，无需迁移和回滚。实际能力以同日期的功能模块文档和项目状态为准。

## 验证结果

- 逐项核对功能入口、内容模型、运行端口和私有数据边界。
- 文档验证结果记录在同日期的文档体系更新中。
