# 个人决策助手

## 定位与状态

状态：🟡 一期可用。助手用于回答“基于当前现状，先做什么”，提供一个优先事项和三个行动步骤；它是建议工具，不是自动执行 Agent。

## 页面入口

- `/assistant`：会话、摘要、归档和删除。
- `/assistant/preview`：问题与工作台上下文的外发预览。
- `/assistant/manual/{task_id}`：人工 ChatGPT/Codex 桥接结果导入。
- 首页“问问助手”：进入同一预览流程。

## 上下文与回答

`AssistantContextBuilder` 默认汇总目标岗位、活跃职位、技能差距、学习任务、项目关卡、知识质量、最近随想、回顾、文章和视频概况，并从本地 FTS 最多补充八条相关结果。

阶段行动只提供首页可见的创业和求职目标的短标题、状态、目标日期、下一交付物及最小行动，以及下个决策节点的名称、日期和状态；生活、证件及仅详情可见的记录不进入这一投影。

每轮有效回答固定包含：一个首要事项、理由、三个步骤、完成标准、来源引用和假设。上下文不足时只提出一个澄清问题。

## 隐私与验证

- 调用前展示完整外发 JSON、来源、Provider、模型地址和 Token 估算。
- 默认排除联系方式、简历与上传文档全文、附件、图片、私有路径、设备信息、密钥和日志。
- 工作台材料一律视为不可信输入，不能改变系统任务或触发工具。
- 来源 ID、技能 ID 和候选操作必须属于本轮白名单；虚构引用会导致整轮失败。
- 数据库只保存意图/结论摘要、引用、假设、候选行动和最终决策，不保存原始问题、完整上下文或完整回答。

## 允许的行动

助手候选行动只允许创建草稿随想或关联现有技能的学习任务。每项操作必须独立确认并保持幂等；助手不能编辑或删除已有内容、改变职位和知识状态、发布公众号或调用外部业务系统。

## 当前限制与失败处理

- 只在桌面工作台提供，不进入 Android PWA。
- 没有可用直接模型时使用七天人工桥接任务，不伪装成实时对话。
- 超时、非法 JSON、虚构 ID、超限输出和危险操作整轮失败，不写摘要历史。
