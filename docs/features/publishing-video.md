# 公众号与视频

## 定位与状态

微信公众号转换状态：✅ 已可用；草稿箱直推状态：🟡 一期可用。视频策划状态：🟡 一期可用。两个流程都只接受 `article`，不会把普通随想、周回顾或知识卡误当作待发布内容。

## 页面入口

| 入口 | 能力 |
|---|---|
| `/publish`、`/publish/{id}` | 文章列表、格式诊断、微信预览、复制和下载 |
| `/settings/wechat` | macOS 钥匙串凭证、显式连接测试和 IP 白名单诊断 |
| `/video` | 视频项目、规格、分镜和制作交接 |
| `/articles/{id}` | 从文章进入公众号或视频流程 |

## 微信转换

- 流水线固定为“安全预处理 → 语义渲染 → 羽白标准主题 → 微信导出清洗”。
- 预览、富文本复制和下载 HTML 使用同一最终正文。
- 主题参考 doocs/md 的经典结构，使用受控主题色、字号、字体、缩进和对齐参数，不开放任意 CSS。
- 只移除重复首个标题、危险链接和私人 Vault 路径，不重写普通 Markdown 结构。
- 本地图片在复制阶段尝试内嵌，公式尝试转为 PNG；单项失败会提示但不阻断正文复制。
- 标题和摘要由作者在公众号后台填写，一键复制只包含正文和固定署名。

### 草稿箱直推

- 直接调用微信官方接口，不运行 MCP、浏览器登录代理或自动发表流程。
- AppID 与 AppSecret 默认位于 macOS 钥匙串，也支持显式后端环境变量兼容；Access Token 只在进程内短期缓存。
- 预检在本机完成：复用当前导出 HTML，将公式转为 PNG、图片转为 Data URL，并校验文章 Revision、正文文本和封面。
- 二次确认后依次上传正文图片、封面并创建草稿。相同文章 Revision、正文和封面默认保持幂等。
- 连接测试会通过只读草稿数量接口检查凭证、IP 白名单和草稿权限；失效 Token 会清缓存并只重试失败操作一次。
- 已由微信托管的 `mmbiz.qpic.cn` 正文图片会直接保留，其余图片必须先安全内嵌再上传。
- 正文图片替换为微信地址后再次校验最终正文的 20000 字符和 1 MB 边界，再调用新增草稿接口。
- 创建草稿超时会记录为“结果未知”，要求先到公众号后台检查，不自动重试。
- 只保存草稿 `media_id`、哈希、状态和脱敏错误阶段；完整正文暂存 24 小时后删除。

公众号风格润色是独立模型候选流程。明确保存候选时会创建新的文章版本并通过 `parent_id` 关联原文章，不覆盖来源。

## 视频工作台

1. 从文章创建视频项目，设置平台、比例、时长、表达类型、受众和风格。
2. 使用确定性规则生成初始分镜，不调用模型。
3. 编辑镜头时长、旁白、画面、字幕和素材引用。
4. 原子导出 Storyboard YAML、旁白稿、SRT、Remotion Props、OpenCut brief 和素材副本。

## 数据、联网与隐私

- 文章 Markdown 是创作权威来源，微信参数只影响当前导出。
- 视频项目保存在私有 `video-projects/`，不会回写文章。
- 微信忠实排版、草稿箱推送和初始分镜不调用模型。
- 只有连接测试和最终确认推送会联网；预览、复制、下载和预检不会访问微信。
- 发布前必须人工确认图片已由公众号重新托管。

## 当前限制与失败处理

- 自动视频渲染、Whisper 转录、口播粗剪和 OpenCut 时间线导入尚未实现。
- 外部图片受浏览器同源限制时保留原地址，并提示手动上传。
- 草稿箱直推要求所有正文图片完成内嵌；任何外部图片或公式回退都会阻止直推，但不影响富文本复制。
- 草稿直推不支持正式发表、群发、更新或删除草稿。
- 随想访问旧发布链接时会返回随想详情提示；相关 POST 会拒绝非文章来源。
