# Android PWA

## 定位与状态

状态：🟡 一期可用。Android PWA 经私人 Tailnet 访问 Mac 上的最小移动网关，用于随手记录、离线编辑未归档随想、联网手工拆卡和离线阅读知识快照。

## 页面与能力

- 移动 `/`：新建文字、标签、分类和最多五张图片。
- 移动 `/ideas`：全部未归档随想的可编辑快照。
- 移动 `/ideas/{id}`：在线或离线编辑，联网时可手工拆卡。
- 移动 `/knowledge`：学科、主题和有效知识卡的只读投影。
- 桌面 `/settings/mobile`：启用网关、配对、设备查看和撤销。

## 离线与同步

- IndexedDB 保存未同步新记录、随想快照、压缩后的离线修改、图片 Blob 和冲突状态。
- 同一随想多次离线编辑压缩成一条操作，并保留首次编辑时的服务端 Revision。
- Revision 一致时原子保存；不一致返回 409，由作者丢弃手机稿或人工合并。
- 稳定幂等键避免网络重试产生重复 Markdown 或图片。
- Service Worker 缓存应用外壳和明确标记的安全知识 HTML，不缓存原始想法 API、附件、最近记录或私人图片。

## 安全边界

- 移动服务只监听 `127.0.0.1:8766`，由 Tailscale Serve 私网代理，禁止 Funnel。
- 设备使用十分钟一次性配对码和哈希会话令牌。
- 只接受配置的 Tailnet HTTPS Host、严格 Origin 和本机代理请求。
- 不开放求职、模型、备份、设置、回收站、状态切换或附件下载。
- 撤销设备后，手机下次联网会清除私人快照；完全离线时无法远程擦除。

## 当前限制与失败处理

- Mac 是唯一权威服务器；知识更新和拆卡仍需要 Mac 在线。
- 手机上的私人副本依赖 Android 锁屏和设备加密。
- Background Sync 受部分 Android ROM 限制时，需要打开应用或点击“立即同步”。
- 手机只追加图片，不负责删除、排序或替换已有附件。
