# Android PWA

手机通过私人 Tailnet 访问 Mac，配对后只显示「日常工作」和「随手记」。安装与配对见 [手机安装与 Tailnet](../operations/mobile-tailscale.md)。

## 日常工作

- 配对后的首页 `/` 展示今日安排、逾期待办、待安排和今日完成，日期按北京时间计算。
- 看板只读。用平时管理待办的桌面浏览器打开羽白工作台「日常工作」，然后在手机点「刷新」。桌面页在前台时约每分钟同步一次，手机显示最近同步时间。
- 来源是 Super Productivity 当前活跃任务。每组最多显示 40 条标题和计划或完成时间，已移入归档的完成任务以桌面记录为准。看板只显示今天的快照，需要手机联网连到 Mac。

## 随手记

- 进入「随手记」可写正文、添加标题、标签、分类及最多五张 PNG、JPEG 或 WebP 图片。离线时保存到手机，联网后自动同步，也可手动重试。
- 「我的随想」可查看和编辑未归档随想。第一次联网打开该页时，手机缓存这些随想用于离线编辑；正文出现 Revision 冲突时，保留手机稿，由你手工合并。
- 知识库和拆卡在桌面使用。手机更新 Service Worker 时清除旧知识缓存，已有随手记、待同步操作和冲突草稿继续保留。

## 权限和数据

- 桌面 `127.0.0.1:8765` 和移动 `127.0.0.1:8766` 分别运行。只有移动网关经 Tailscale Serve 暴露给私人 Tailnet，配对码单次有效，设备可在桌面撤销。
- 写入须通过配对会话、Origin 和 CSRF 校验，离线操作使用幂等标识。手机看板响应不进入离线缓存，任务的备注、项目及附件不进入快照。
- 主动清除手机副本，或设备联网后发现配对已撤销，会清除随想快照、未同步操作及冲突草稿。离线时依赖手机的锁屏和存储加密。
