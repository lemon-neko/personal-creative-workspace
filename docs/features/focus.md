# 阶段行动

## 定位与入口

状态：🟡 一期可用。`/focus` 管理一个有起止日期的个人阶段，依次记录目标、可验收交付物和最小行动；`/focus/checkin` 保存本周实际完成、空转之处和下周重点。旧待办 `/legacy/planner` 汇合独立待办、今日重点和到期事项；可快速添加、勾选完成、撤销、展开编辑或交接 AI；今日内分组显示逾期、未完成与已完成。P0 目标是主线，P1/P2 是分支，按完成行动数展示进展。阶段事项定位到目标详情里的原行动；`/focus/history` 可回看其他阶段。

首页「日常工作」使用 Super Productivity，见[日常工作与 AI 工作流](workbench-plugins.md)。旧待办页面的月历可翻月、选择日期或跳到指定日期，时间轴按半小时展示当天安排。拖动待办的手柄可以改日期、改时间、取消安排或完成，也可以用行内表单调整。计划开始时间和截止日期分别倒计时，截止日期按北京时间当天结束计算。

「待办列表」是查看事项的入口；「待安排」是日历左侧的暂存区，收纳还没有单独排程、也没有列在所选日期右侧的未完成待办。选日后直接添加，默认进入当天全天区；需要具体时间时，可以点时间格创建，或拖动已有待办。

新增、调整排程、完成、恢复和首次交给 AI 会记到当天的活动时间轴。此前的待办从现有日期和今日重点进入视图，历史活动从本次更新开始记录。

## 使用规则

- `/legacy/planner?board=upcoming` 列出未来的独立待办、未安排到今天的可见阶段行动。放到今日会改独立待办日期；阶段行动使用已有三项今日重点机制，不改截止日期。
- 待办操作按同源表单提交，支持局部刷新；关闭脚本仍可添加、完成、编辑和排入今日。撤销恢复完成前的状态，并检查状态是否已被别处改动。

- 目标、交付物和行动都由作者手工维护，状态为计划中、进行中、受阻、完成、暂缓。日期已过只提示复核，不自动修改状态。
- 决策节点也有手工状态；标记完成或暂缓前持续显示，到期后仍留在旧待办的待确认区提示复核。
- 本周重点从交付物中手工选择，今日重点从行动中手工选择；两者各最多三项。上海时区的周一是周起点。
- 目标可设为“首页显示概况”或“只在详情显示”。后者不会进入旧待办的重点列表；切换为仅详情可见时，已有重点标记会清除。
- 对旧待办可见、未完成且未暂缓的行动，可以交接 AI 或运行规则工作纸；独立待办也可以交接。每个事项至多关联一个任务；验收后可返回原事项，再手工更新实际进展。已有任务在目标改为仅详情可见后只从原行动或详情链接进入，不再出现在旧待办、旧任务和运行总览。
- 创业目标可保存手工维护的 HTTPS 协作链接。工作台不访问该链接，也不复制团队项目任务。
- 阶段复盘与内容周回顾相互独立；内容周回顾继续汇总随想，不把行动状态当作随想正文。

## 数据与隐私

结构化记录只保存在仓库外的私有 `workspace.db`，通过统一迁移序列升级。阶段计划不会进入公开静态资源、全局搜索或 Android PWA。个人助手只读取允许显示概况的创业与求职目标的短标题、状态、日期、下一交付物及最小行动，以及下个决策节点的名称、日期和状态，并沿用外发预览；生活与仅详情可见的记录不进入助手上下文。

一次性导入支持按稳定阶段标识幂等写入。导入项默认为“计划中”，不会根据来源中的目标描述推断实际完成。真实私人文字不进入仓库代码、文档、测试或日志。
