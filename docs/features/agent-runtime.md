# 旧任务运行时

状态：🧪 实验性。桌面 `/legacy/tasks` 管理旧任务，`/runs` 查看运行；`/artifacts/{id}` 查看私有候选产物。从今日待办或阶段行动交接的任务保留原事项链接，同一事项重复交接只复用一个任务。新流程见 [日常工作与 AI 工作流](workbench-plugins.md)。

旧任务页按待你决定、待验收、运行中、待执行、需处理和已结束展示最新运行。模型预览确认后可离开页面，服务会在后台运行。遇到问题会保存决策并暂停，用户回答后再次预览确认即可继续。重启时仍在运行的任务会标记为中断，可重新规划。

1. 交接事项或单独创建任务，按任务类型生成学习、研究、创作或构建计划。
2. 需要时先补充任务材料，再选择「预览并运行 AI」，检查实际指令、材料、模型及 Token 上限后确认。模型只收到任务标题、目标和角色；继续运行时还会收到决策问题和所选选项。无模型时可选择「运行本地计划」，规则工作纸使用本地只读检索。
3. 模型能直接提交一份草稿，也能提出一个必须由作者选择的决策。等待期间只保存短问题与选项，不保持模型会话。回答只保存选择；再次预览并确认后才继续。每次运行最多一个决策。
4. 检查并接受候选产物。验收只完成运行；返回原待办后，由本人更新实际进展。失败或取消可以重新规划，保留旧记录。

旧待办页面的「待我确认」汇合下一项阶段决策，以及最多三条待验收、待决策、失败、待继续或待执行的运行。仅详情可见的目标不进入首页或任务、运行总览。

任务、运行、步骤、决策、脱敏工具摘要和产物登记位于私有 `workspace.db`；候选正文位于 `working/agent-artifacts/`（目录 0700、文件 0600）。模型用量由 `ModelGateway` 记录，运行记录不保存完整提示词、密钥或请求响应。查看或验收时会核对正文是否与登记的 SHA-256 一致；内容缺失或损坏时不能验收。标准加密备份只包含主库登记，不包含产物正文。技术边界见[Agent Runtime 架构](../architecture/agent-runtime.md)。

外部 Provider 默认关闭。模型没有通用工具或命令执行能力，不自动读取知识库、简历等领域资料，也不能发布或写入正式内容。此流程独立于决策助手及手机端。等待人工决策可跨服务重启恢复；后台运行由用户确认触发。定时调度、自动重试与外部通知暂未接入。
