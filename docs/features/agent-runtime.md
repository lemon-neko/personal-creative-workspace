# 本地任务运行时

## 功能定位

状态：🧪 实验性。

本地任务运行时为工作台补充统一的“项目 → 任务 → 运行 → 步骤 → 工具摘要 → 产物”结构。它用于组织跨模块目标和记录执行轨迹，不替代个人决策助手，也不直接成为自治 Agent。

主要入口：

- `/tasks`：项目、任务列表与任务创建。
- `/tasks/{id}`：目标、角色、运行和产物。
- `/runs`：全部运行记录。
- `/runs/{id}`：步骤、脱敏工具调用和人工确认。
- `/artifacts/{id}`：私有任务工作纸。

## 当前闭环

```text
作者创建目标
→ 规则式角色分派
→ 生成三步本地计划
→ 查询本地 FTS5 索引
→ 生成私有任务工作纸
→ 确定性 Reviewer 检查
→ 作者接受或取消
```

当前角色按照任务类型映射为学习、研究、创作和构建。角色是运行策略，不是四个独立聊天机器人。Chief 使用确定性规则完成分派，运行过程不调用模型。

## 数据与产物

任务元数据、运行状态、步骤、工具调用摘要和产物登记保存在 `workspace.db` 的 `agent_core` 子系统。产物正文位于私有 `working/agent-artifacts/`，目录权限为 `0700`，文件权限为 `0600`。

工具记录只保存“本地关键词数量”和“结果数量”等摘要，不保存完整查询正文、模型 Prompt、绝对路径、密钥或外部响应。任务目标本身作为作者明确创建的任务内容保存在私有主库。

## 安全边界

- 页面加载、规划和本地运行不联网、不调用模型。
- 产物默认处于“待确认”，接受前不会进入知识库、文章或其他领域模块。
- 接受产物只确认运行完成，不会自动创建知识卡、发布内容或执行外部系统。
- `/assistant` 继续只负责来源压缩的建议和有限候选行动，不会调用本运行时执行任务。
- 手机端不提供任务、运行和产物数据。
- 后续模型能力仍必须经过 `ModelGateway` 外发预览和人工确认。

## 当前限制

- 第一版只支持三步同步本地运行，没有后台队列、并行任务、断点续跑或定时调度。
- 只登记本运行时产生的工作纸；尚未为既有 Markdown、视频、简历和模型任务建立统一 Artifact 投影。
- 没有通用外部工具注册或代码执行；当前唯一工具是本地只读检索。
- 没有长期 Agent Memory；上下文继续来自既有 FTS5、知识库和明确任务目标。
