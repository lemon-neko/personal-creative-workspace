# 求职与学习

## 定位与状态

状态：🟡 一期可用。该模块把候选人事实、真实项目证据、职位要求、技能差距和开源研读任务连接起来，但不抓取招聘网站、不自动投递。

## 页面入口

| 入口 | 能力 |
|---|---|
| `/career` | 求职驾驶舱 |
| `/career/profile` | 候选人档案与导入确认 |
| `/career/documents` | 私有文档管理 |
| `/career/projects` | 真实项目证据库 |
| `/career/resumes` | 简历版本管理 |
| `/career/jobs` | 职位和阶段时间线 |
| `/learning` | 岗位雷达、能力矩阵和四周开源研读 |
| `/learning/campaigns/{id}` | 历史项目战役和证据 |

## 核心流程

```text
目标岗位 → 共性能力 → 当前证据与差距 → 开源参考项目 → 手搓任务与验收证据
```

- 候选人档案只保存作者确认过的事实。
- 项目证据记录职责、技术栈、问题、行动、结果和量化证据。
- 职位由作者手工粘贴 JD 或上传文件，并维护状态时间线。
- 岗位雷达使用带日期的静态快照，将要求归为 Agent、RAG、服务工程、安全协议、评测可观测和部署稳定性六个能力域。
- 四周路线每周研读一个主要开源仓库，并要求一个自己重写的最小模块、Commit SHA、测试结果和复盘。
- Agent Reliability Arena 和旧学习任务只归档或暂停，历史证据不删除。

## 数据、模型与隐私

- 结构化关系位于私有 `workspace.db`；上传文档使用随机存储名存放在仓库外。
- PDF、DOCX、Markdown、TXT、PNG 和 JPEG需通过扩展名、签名、大小和路径校验。
- 简历和 JD 提取只产生候选，保存前必须人工核对。
- 页面加载不会访问招聘网站、GitHub 或调用模型。
- 联系方式、简历正文和项目证据不会进入公开路由或静态资源。

## 当前限制与失败处理

- 不自动生成 PDF，不抓取 URL，不发送邮件或自动投递。
- 学历、论文和年限等非短期差距不会伪装成四周任务。
- 岗位与 GitHub 信息不会自动刷新；更新时需手工保存新的日期快照。
- 文档提取失败不会自动采信部分结果。
