# 功能清单

本文件是羽白工作台“当前能做什么”的权威来源。成熟度总览和近期计划见 [项目状态](../PROJECT_STATUS.md)，具体操作步骤见 [使用手册](USER_GUIDE.md)。

状态说明：✅ 已形成完整闭环并有测试覆盖；🟡 核心路径可用但仍需真实使用验证；🧪 可体验但不承诺稳定；⏳ 当前未实现。

## 工作台、想法与生命周期

| 状态 | 功能 | 页面入口 | 当前能力与边界 |
|---|---|---|---|
| ✅ | 单页驾驶舱 | `/` | 随手记录、全文搜索、待整理/文章草稿/已成稿/全部分组、状态切换和近期状态聚合 |
| ✅ | 通用想法库 | `/ideas` | 正文必填，标题与摘要可自动生成；支持标签、分类、类型、状态和日期筛选 |
| ✅ | Markdown 编辑 | `/ideas/{id}` | 安全预览、未知 Properties 保留、Obsidian Revision 冲突保护和来源追踪 |
| ✅ | 内容生命周期 | `/ideas`、`/trash` | 草稿、已成稿、归档、移入回收站、恢复和二次确认永久删除 |
| ✅ | 通用周回顾 | `/reviews` | 默认使用确定性规则，同一自然周幂等；定时任务不调用模型 |
| ✅ | 私有配图 | `/assets/{name}` | 图片位于私有目录，通过受保护路由读取，不进入静态资源或 Git |
| ✅ | 统一搜索 | `/search`、`Cmd+K` | SQLite FTS5、中文子串回退和结构化索引，全程不调用模型或 Embedding API |

内容类型固定为 `thought`、`weekly-review` 和 `article`；状态固定为 `draft`、`published` 和 `archived`。界面中的“已成稿”对应兼容字段 `published`，不代表公网发布。

## Obsidian 与分层知识库

| 状态 | 功能 | 页面入口 | 当前能力与边界 |
|---|---|---|---|
| ✅ | 单一正式知识结构 | `/knowledge` | 固定为“知识首页 → 学科地图 → 主题地图 → 知识卡 → 原始来源” |
| 🟡 | 多父级知识地图 | `/knowledge/maps/{id}` | 主题可同时属于多个学科；无效父级和循环关系会被拒绝 |
| 🟡 | 原子知识卡 | `/knowledge/cards/{id}` | 类型为概念、判断、问题、方法或观察；必须关联至少一个来源 |
| ✅ | 来源与历史 | 知识卡详情 | 支持 `derived_from`、`related`、`extends`、`supports`、`contrasts`、`superseded_by` 和有效时间 |
| ✅ | 核心知识图 | `/knowledge` | 默认只显示地图、有效知识卡和明确关系；概念只用于筛选，来源点击卡片后展开 |
| ✅ | Obsidian 零复制 Vault | `/settings/obsidian` | Obsidian 与工作台直接编辑同一份 Markdown，不建立同步副本 |
| ✅ | Templates 收件箱 | `/settings/obsidian` | 提供学科地图、主题地图和知识卡模板；确认后补齐稳定 ID 并进入正式目录 |
| ✅ | 外部编辑协调 | `/settings/obsidian` | 扫描合法修改、保留未知 Properties；并发变化返回冲突，不覆盖新正文 |
| ✅ | 旧结构安全整理 | `/settings/obsidian` | dry-run 标记已覆盖、冲突和未拆卡；确认后重命名并清理已覆盖字段，可从私有快照回滚 |
| 🟡 | 知识拆卡 | `/models`、`/knowledge` | 可手工创建，或由本地模型/人工任务产生候选；未经确认不写入知识卡 |
| 🟡 | 材料库 | `/library` | 保存笔记、URL 和本地文档引用，维护阅读状态并创建派生想法；URL 不自动抓取 |

原始想法中的旧 `subjects`、`concepts` 和 `relations` 仅保持读取兼容，不再驱动第二套知识索引或概念网络。

## 公众号与视频创作

| 状态 | 功能 | 页面入口 | 当前能力与边界 |
|---|---|---|---|
| ✅ | 发布工作台 | `/publish`、`/publish/{id}` | 从想法、周回顾或文章进入微信公众号预览 |
| ✅ | 微信正文转换 | 发布详情 | 羽白标准版行内样式；复制富文本和纯文本，标题与摘要留在公众号后台填写 |
| ✅ | 图片与公式处理 | 发布详情 | 本地图片复制前尝试内嵌；公式尝试转为 PNG，失败保留可读文本并提示 |
| 🟡 | 幻想栈风格候选 | 发布详情、`/models` | 仅在明确触发模型任务后生成候选稿；忠实转换始终不依赖模型 |
| ✅ | 来源保护 | 发布详情 | 候选文章另存为 `article` 并通过 `parent_id` 关联来源，原文不被覆盖 |
| 🟡 | 视频项目 | `/video` | 设置平台、比例、时长、表达类型、受众和风格，从文章生成可编辑初始分镜 |
| 🟡 | 分镜编辑 | `/video` | 逐镜头维护时长、旁白、画面、字幕和素材引用，不修改来源文章 |
| 🟡 | 制作交接 | `/video` | 原子导出 Storyboard YAML、旁白稿、SRT、Remotion Props、OpenCut brief 和素材副本 |
| 🧪 | 自动视频生产 | 无 | Remotion 渲染、Whisper 转录、口播粗剪和 OpenCut 时间线自动导入尚未接入 |

| 🟡 | 职位跟踪 | `/career/jobs` | 手动记录 JD、公司、岗位、来源、状态、备注和阶段时间线；不抓取或自动投递 |

## 模型与成本治理

| 状态 | 功能 | 页面入口 | 当前能力与边界 |
|---|---|---|---|
| ✅ | 统一 ModelGateway | `/models` | Provider 固定为 `rules`、`local`、`manual`、`external` |
| ✅ | 默认零 API 成本 | 全站 | 没有模型时仍可记录、搜索、规则回顾、忠实排版和手工知识整理 |
| ✅ | 外发预览 | `/model-tasks/{id}` | 展示来源、估算 Token 和即将发送的内容，由作者删除或脱敏后确认 |
| ✅ | 本地模型 | `/models` | 只接受回环 OpenAI-compatible 地址，兼容 Ollama 与 LM Studio |
| ✅ | 人工桥接 | `/model-tasks/{id}` | 复制任务包到 ChatGPT/Codex，再导入并校验结构化结果 |
| ✅ | 外部模型开关 | `/models` | 默认关闭；配置环境变量后仍需逐次确认，不读取订阅登录态或 Cookie |
| ✅ | Token 与费用账本 | `/models` | 只保存任务类型、Provider、模型、Token、耗时、状态和费用，不保存正文与响应 |
| 🟡 | 五类任务 | `/models` | 知识拆卡、周回顾、公众号候选、简历档案和 JD 技能均有输入/输出硬上限 |

定时周回顾只能运行规则版。模型结果始终是候选内容，不能未经确认修改来源、档案事实或职位状态。

## Android PWA 与 Tailnet

| 状态 | 功能 | 页面入口 | 当前能力与边界 |
|---|---|---|---|
| ✅ | 可安装 PWA | 移动网关 `/` | Android 浏览器安装到桌面，以独立窗口运行 |
| ✅ | Tailnet 私网访问 | 桌面 `/settings/mobile` | Tailscale Serve 只代理 `127.0.0.1:8766`，禁止 Funnel |
| ✅ | 设备配对与撤销 | 桌面设置、移动 `/pair` | 十分钟一次性配对码、设备会话哈希、CSRF 和桌面端撤销 |
| ✅ | 移动记录 | 移动 `/` | 正文、可选标题/标签/分类，以及最多 5 张 PNG/JPEG/WebP 图片 |
| ✅ | 离线队列 | PWA | IndexedDB 暂存未同步记录；恢复网络后重试，幂等键避免重复内容 |
| ✅ | 最近记录 | 移动 `/` | 在线读取最小投影，不开放编辑、归档和删除 |
| ✅ | 分层知识阅读 | 移动 `/knowledge` | 在线浏览学科、主题和当前有效知识卡；来源只显示标题、摘要和时间 |
| ✅ | 知识零缓存 | 移动知识页 | 每次实时读取 Mac，使用 `no-store`，不进入 Service Worker 或 IndexedDB |
| ✅ | 最小权限 | 移动网关 | 不开放求职、模型、备份、设置、回收站、附件下载或桌面管理路由 |

Mac 是唯一权威服务器。Mac 离线时手机仍可记录到本地队列，但无法读取最近内容或知识库。

## 隐私、安全与恢复

| 状态 | 功能 | 页面入口 | 当前能力与边界 |
|---|---|---|---|
| ✅ | 本地桌面边界 | 全站 | 固定回环监听并校验客户端、Host、代理头、CSRF 和同源请求 |
| ✅ | 浏览器安全头 | 全站 | `no-store`、CSP、禁止嵌入、MIME 嗅探保护；OpenAPI/Swagger/ReDoc 关闭 |
| ✅ | 仓库外数据 | `/settings` | 默认位于 macOS Application Support，目录/文件权限为 `0700/0600` |
| ✅ | 上传保护 | 求职、移动和素材入口 | 随机存储名、真实签名和大小校验，拒绝 HTML、SVG、宏文档和可执行内容 |
| ✅ | Git 安全守卫 | CI | 拒绝私有数据、密钥和公网部署配置进入版本库 |
| 🟡 | AES-256 备份 | `/settings/backups` | 加密导出、清单、版本、SHA-256、恢复预演和替换前回滚快照 |
| ✅ | 公开区移除 | 全站 | `/garden` 不存在；`published` 只表示“已成稿” |

备份不包含 API Key、会话密钥、模型临时任务、`.obsidian/` 配置或旧备份。完整边界见 [安全说明](SECURITY.md)。
