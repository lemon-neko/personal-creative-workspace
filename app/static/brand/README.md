# 羽白品牌标识

核心意象是“羽化成光”：青蓝羽毛代表持续观察与表达，暖黄四芒星代表“熠”的微光和灵感被点亮的一瞬。

## 文件

- `yubai-logo.svg/png`：主标志，用于页面、署名和较宽版面。
- `yubai-mark.svg/png`：方形图标，用于头像、favicon 和小尺寸场景。
- `yubai-watermark.svg/png`：配图水印，用于公众号插图。

## 品牌色

- 青蓝：`#159FB5`
- 深灰：`#262B2D`
- 暖黄：`#F2C94C`
- 浅青灰：`#EAF5F6`
- 白色：`#FFFFFF`

## 配图规则

- 默认将 `yubai-watermark` 放在右上角。
- 水印宽度使用画布宽度的 10% 至 14%，最小不低于 120px。
- 水印与上、右边缘至少保留画布宽度 3.5% 的安全距离。
- 浅色背景使用标准彩色版；复杂背景先增加白色留白区，不直接添加阴影或描边。
- 不拉伸、不旋转、不改变图形与字标间距，不让图像模型重新生成 Logo。

## 内容配色

技术信息图以白底、深灰正文和青蓝强调为主；暖黄只用于光点、关键状态或极少量趣味元素。
